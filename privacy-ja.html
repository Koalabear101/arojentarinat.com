当社について

Arojen Tarinat のゲームおよびこのウェブサイトは、フィンランドの独立した開発者である Juuso Honkonen と Vilho Valkeala が開発しています。両名は本ポリシーに記載された個人データの管理者です。プライバシーに関するご質問は、contact@arojentarinat.com までご連絡ください。

本ポリシーは、Arojen Tarinat の Android アプリ、ブラウザ版のゲーム、およびこのウェブサイトを対象とします。

法的根拠

当社は、本ポリシーに記載された目的のためにのみ、かつ GDPR で認められた法的根拠に基づいてのみ個人データを処理します。

  • ゲームおよびお客様がご要望の機能の提供（アカウント、クラウドセーブ、マルチプレイヤー、Premium）：お客様との契約の履行（第6条(1)(b)）。
  • ゲームプレイのアクセス解析：お客様の同意（第6条(1)(a)）。解析に関するダイアログでいただいた同意です。設定からいつでも同意を撤回できます。
  • Moose AIアシスタント：お客様のご要望に基づく、お客様との契約の履行（第6条(1)(b)）。アシスタントは任意の機能であり、ゲームの他の部分はアシスタントなしでも動作します。
  • 広告：お客様の同意（第6条(1)(a)）。必要な場合は Google の同意ダイアログを通じて取得します。拒否された場合、法律が認める範囲で、広告はパーソナライズされていない広告に限定されます。
  • クラッシュレポート、共有ゲームコンテンツ、サービスの安全確保と不正利用の防止：エラーの修正、ゲームの動作維持、プレイヤーの保護に関する当社の正当な利益（第6条(1)(f)）。
  • 通知：お客様の許可（同意）。端末の設定から撤回できます。
  • 購入および会計：お客様との契約の履行（第6条(1)(b)）、および法的義務の遵守（第6条(1)(c)）。
  • サポートのご依頼：お客様へ回答することに関する当社の正当な利益（第6条(1)(f)）、または契約締結前にお客様が要請する手続き（第6条(1)(b)）。
  • ウェブサイトの運営とセキュリティ：サイトの提供および不正利用からの保護に関する当社の正当な利益（第6条(1)(f)）。

お使いの端末上のデータ

お客様のゲームのセーブデータ、セーブスロット、設定、実績、統計は、お客様の携帯電話に保存されます。当社がこれらを見ることはできません。ゲームをアンインストールするか、ゲームのデータを消去するまで保存されたままです。Android は、お客様ご自身の管理下にある端末のバックアップにこれらを含める場合があります。

アカウントとクラウドセーブ

アカウントの作成は任意です。すべてをゲストとしてプレイできます。メールアドレスまたは Google でサインインすると、当社は以下を保存します。

  • お客様のメールアドレス、または「Google でサインイン」を選択したときに Google が共有する識別子とメールアドレス。
  • 進行状況のコピー：統計、解除された実績、セーブデータ。別の携帯電話でも続けられるようにするためです。

アカウントがない場合でも、初めてオンラインでプレイする際にゲームは匿名の識別子を作成します。これは、サーバーがプレイヤーを区別できるようにするためです。法的根拠は、お客様との契約の履行（お客様が要求したゲームの提供）です。アカウントとこのデータは、いつでも削除できます。詳しくはデータの削除をご覧ください。

マルチプレイヤー、チャット、ボイスメッセージ

オンラインでプレイする場合、当社は、お客様が選んだ名前、作成または参加したルーム、お客様の勢力と手番、そして送信したメッセージを処理します。

  • チャットメッセージは、同じ対戦のほかのプレイヤーに表示されます。
  • ボイスメッセージは最大30秒で、録音ボタンを押している間だけ録音されます。マイクはそれ以外の目的には使用されず、Android は最初にお客様の許可を求めます。
  • プレイヤーをミュートし、メッセージを通報することができます。通報は、当社が内容を確認して不正利用に対処できるよう保存されます。

チャットで個人情報を共有しないようお願いします。法的根拠は、お客様との契約の履行、およびコミュニティの安全を守るという当社の正当な利益です。アカウントを削除した場合、進行中の対戦は AI がお客様の勢力を率いて続行されます。

共有ゲームコンテンツ

生成されたカード画像とそのメタデータは Supabase に保存され、ゲーム内でプレイヤーに表示されます。当社は、共有ゲーム機能を提供するため、またサービスの安全性と不正利用の防止を維持するために、正当な利益に基づいてこのコンテンツを処理します。ゲーム内に残る限り保存し、お客様に紐付けられる場合は要請に応じて削除します。

Moose AIアシスタント

Moose は、ルールに関する質問に答える任意の AI アシスタントです。初めて利用する前に、ゲームはお客様のメッセージが OpenAI に送信されることをお知らせし、個人情報を共有しないようお願いします。Moose に質問すると、現在のメッセージと、そのセッションにおける直近のメッセージ最大6件が、当社のサーバーである Supabase Edge Function を経由して OpenAI に送信され、回答が生成されます。これらと一緒に、お客様の氏名、アカウント、その他の個人データを送信することはありません。

当社は AI のチャット記録をデータベースに保存せず、会話を当社独自のモデルの学習に使用することもありません。会話はアプリ内に現在のセッションの間だけ残ります。チャット画面から、不適切または有害な AI の回答を通報できます。OpenAI は不正利用の監視のため、リクエストを最大30日間保持する場合がありますが、デフォルトでは、そのモデルの学習には使用しません。メッセージに個人情報や機微な情報を含めないでください。

アクセス解析とクラッシュレポート

ゲームプレイのアクセス解析（お客様の同意がある場合のみ）

お客様が初めてゲームを開いたときに、仮名化された利用統計を収集してよいかどうかをお尋ねします。同意いただいた場合、ゲームはランダムなインストール識別子、セッション識別子、プラットフォームとアプリのバージョン、セッションの長さ、そしてセッションの開始、キャンペーンの開始や終了、進行状況、設定の変更、実績の解除などのゲームプレイイベントを送信します。これらのデータは当社の Supabase データベースに保存されるほか、Google Play 版では Firebase 向けの Google アナリティクスにも送信されます。設定からいつでも選択を変更できます。アクセス解析をオフにすると、送信待ちのデータも携帯電話から削除されます。法的根拠はお客様の同意であり、同意を撤回しても、撤回前に行われた処理には影響しません。

クラッシュレポート

アプリがクラッシュすると、Firebase Crashlytics がクラッシュレポートを送信します。これには、エラーの技術的な詳細、お客様の携帯電話の機種、Android のバージョンとアプリのバージョン、およびランダムなインストール識別子が含まれます。当社はこれを、バグの発見と修正のためにのみ使用します。これは、正常に動作するゲームに対する当社の正当な利益に基づきます。

広告と同意

無料版では Google AdMob のバナー広告が表示されます。AdMob とそのパートナーは、広告の表示と測定、および不正防止のために、広告 ID、IP アドレス、おおよその位置情報、端末情報、広告との操作を処理する場合があります。

欧州経済領域、英国、スイスでは、パーソナライズされた広告が読み込まれる前に、Google の User Messaging Platform（UMP）の同意ダイアログが表示されます。このダイアログでは、広告をどのようにパーソナライズするかをお尋ねします。拒否された場合、法律が認める範囲で、パーソナライズされていない広告のみを表示します。後から、ゲーム内の広告同意オプション、または携帯電話の設定で選択を変更できます。携帯電話の設定で広告 ID をリセットまたは削除することもできます。一部の広告処理については、Google が独立した管理者として行動します。詳しくは policies.google.com/technologies/ads をご覧ください。

Arojen Premium をご利用の場合、ゲームは広告をまったく読み込みません。

Arojen Premium と購入

Arojen Premium は、広告を削除する任意の月額サブスクリプションです。Google Play を通じて販売されます。決済は Google が行い、当社がお客様のカードや支払い情報を見ることはありません。サブスクリプションが有効であることを確認するため、当社のサーバーは購入トークンを Google Play で照合し、サブスクリプションの状態（有効、更新中、期限切れ、および終了日）を保存します。法的根拠は、お客様との契約の履行、および会計に関する当社の法的義務です。

通知とアプリ内メッセージ

Android 13 以降では、ゲームはニュースやイベントに関する通知を送信する前に、お客様の許可を求めます。通知を届けるため、Firebase Cloud Messaging はお客様のインストールにランダムなトークンを割り当てます。ゲーム内のお知らせは Firebase In-App Messaging で表示されます。携帯電話の設定からいつでも通知をオフにできます。

このウェブサイト

このウェブサイトは、Cookie、アクセス解析、トラッカーを一切使用せず、すべてのフォントと画像はサイト自体から配信されます。ホスティング事業者である Vercel は、ページの配信とサイトの保護のために、お客様の IP アドレスとブラウザの情報を短期間のサーバーログで処理します。お問い合わせフォームは、お客様ご自身のメールアプリを開くだけです。サイト自体が何かを送信または保存することはありません。

サービスプロバイダーと国外移転

当社は、ゲームとこのウェブサイトを運営するために、以下のプロバイダーを利用しています。これらのプロバイダーは、データを保護する契約に基づき当社に代わってデータを処理します。ただし、上記で説明したとおり、プロバイダーが独立した管理者として行動する場合は除きます。

プロバイダー用途
Supabaseゲームサーバーとデータベース：アカウント、クラウドセーブ、マルチプレイヤー、チャット、ボイスメッセージ、共有カードコンテンツ、アクセス解析イベント、AIリクエストを OpenAI に渡す Edge Function
OpenAIMoose AIアシスタントの回答：現在のメッセージと直近のメッセージ最大6件のテキスト
Google Firebaseクラッシュレポート、Google アナリティクス（同意がある場合）、通知、アプリ内メッセージ
Google AdMob無料版の広告
Google Playアプリの配信、アプリ内アップデートとレビュー、サブスクリプションの支払い
Cloudflareマルチプレイヤーのルームを開く招待リンク
Vercelこのウェブサイトのホスティング

OpenAI の公開 API 利用規約には、API を通じて送信されたデータはデフォルトではモデルの学習に使用されないと記載されています。同規約に基づき、OpenAI はサービスの提供と不正利用の検出のために、最大30日間データを保持する場合があります。詳しくは、OpenAI の API データ利用に関するドキュメントをご覧ください。

Supabase、OpenAI、Google、Cloudflare は、欧州経済領域外の米国やその他の国でデータを処理する場合があります。その場合、プロバイダーが認証を受けていれば EU-US Data Privacy Framework、または欧州委員会の標準契約条項（SCC）に依拠します。当社はお客様の個人データを販売しません。

データの保存期間

  • お客様の携帯電話上のゲームのセーブデータと設定：ゲームをアンインストールするか、データを消去するまで。
  • アカウントとクラウドセーブ：お客様がアカウントを削除するまで。
  • チャットとボイスメッセージ：対戦が存在する間。アカウントと共に削除されます。
  • アクセス解析イベント：最長14か月。その後削除されます。
  • 共有ゲームコンテンツ：ゲーム内に残る限り。お客様に紐付けられる場合は要請に応じて削除します。
  • AIアシスタントのメッセージ：当社はチャット記録として保存しません。現在のセッションの間はアプリ内に残ります。OpenAI はリクエストを最大30日間保持する場合があります。
  • クラッシュレポート：Firebase Crashlytics で最長90日。
  • サブスクリプションの記録：サブスクリプションが続く間、その後は会計法で必要な期間。
  • 当社へのメール：案件解決後、最長12か月。
  • 広告データ：Google 自身のポリシーに定められたとおり。

データの削除

ゲーム内で：設定を開き、アカウントに進んで「アカウントを削除」をタップし、確認してください。お客様のアカウントとそのデータは直ちに削除され、ゲームはこの携帯電話でゲストとして続行します。

メールで：ゲームをインストールしていない場合は、サインインに使用したアドレスからメールを送るか、使用した Google アカウントをお知らせください。アカウントがお客様のものであることを確認し、30日以内に削除します。

アカウントを削除すると、メールアドレスまたは Google サインイン、クラウド上の進行状況のコピー、セーブデータと実績、すべての対戦におけるチャットとボイスメッセージ、そしてマルチプレイヤーでの名前（「Player」に変更されます）が削除されます。ボイスメッセージの音声ファイルは、整理されるまで当社の非公開ストレージに残る場合があります。誰にも表示されません。直ちに削除を希望される場合は、当社にメールしてください。アカウントに紐付けられていない仮名化されたゲームプレイ統計は、最長14か月間保持されます。携帯電話に保存された進行状況は、ゲームをアンインストールするか、データを消去するまで残ります。

Arojen Premium：アカウントを削除しても、サブスクリプションは解約されません。Google Play アプリの「お支払いと定期購入」から「定期購入」を開いて解約してください。Google は購入に関する独自の記録を保持します。

詳しい手順はアカウントを削除のページにあります。

お客様の権利

GDPR に基づき、お客様はご自身のデータへのアクセス、訂正または削除、処理の制限または異議申し立て、そしてポータブルな形式でのデータの受領を求める権利を有します。また、撤回前に行われた処理に影響を与えることなく、いつでも同意を撤回する権利があります。これらの権利を行使するには、contact@arojentarinat.com にメールしてください。該当するデータを特定できるよう、サインインに使用したメールアドレス、またはアクセス解析に関するご要望の場合は設定に表示される識別子を記載してください。1か月以内に回答します。

フィンランドのデータ保護当局である Office of the Data Protection Ombudsman（データ保護オンブズマン事務所）、またはお住まいの国の監督当局に苦情を申し立てることもできます。

セキュリティ

当社は、収集するデータを必要最小限に抑え、保有するデータを保護します。アプリと当社のサービス間の通信は HTTPS/TLS を使用し、アプリは暗号化されていない HTTP 通信を許可しません。当社の Supabase テーブルは Row Level Security を使用しており、サービスロールキーがアプリに組み込まれることはなく、OpenAI API キーはサーバー側のみで保管されます。当社の包括的な対策、セキュリティインシデントへの対応方法、および脆弱性の報告方法については、セキュリティポリシーに記載しています。

年齢制限と児童

Arojen Tarinat は、他のプレイヤーとのチャット、広告、AI アシスタントを含むため、18歳以上の成人を対象としています。児童を対象としたものではありません。当社は、児童から個人データを故意に収集することはありません。児童が個人データを提供したと思われる場合は、当社までご連絡ください。削除いたします。

本ポリシーの変更

ゲームまたはこのウェブサイトが個人データの利用方法を変更する場合、当社は本ポリシーと冒頭の日付を更新します。重要な変更については、変更が有効になる前に、ゲーム内またはこのウェブサイト上でもお知らせします。

プライバシーに関するご要望は、contact@arojentarinat.com までメールしてください。セキュリティの報告については、セキュリティポリシーをご覧ください。
