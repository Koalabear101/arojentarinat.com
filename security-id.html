Kebijakan keamanan

Kami mengumpulkan data sesedikit mungkin dan melindungi data yang kami simpan. Kebijakan ini menjelaskan langkah-langkah pengamanan utama kami dan melengkapi Kebijakan privasi.

In English: Security policy

Terakhir diperbarui 1 November 2026

Enkripsi saat transmisi

Lalu lintas antara aplikasi dan Supabase, fungsi server AI, serta layanan iklan Google menggunakan HTTPS/TLS. Aplikasi tidak mengizinkan lalu lintas HTTP yang tidak terenkripsi.

Enkripsi saat disimpan

Supabase mengenkripsi penyimpanan basis data. Simpanan game tetap berada di penyimpanan pribadi aplikasi di perangkat Anda.

Kontrol akses

Row Level Security (RLS) diaktifkan pada setiap tabel Supabase, sehingga kunci publik hanya dapat melakukan apa yang diizinkan oleh aturan, misalnya menambahkan peristiwa analitik dan membaca konten bersama. Kunci service-role tidak pernah disertakan dalam aplikasi.

Pengelolaan rahasia

Kunci API OpenAI adalah rahasia sisi server dari Supabase Edge Function dan tidak disertakan dalam aplikasi.

Pencegahan penyalahgunaan

Fungsi AI membatasi jumlah permintaan per klien dan hanya meneruskan pesan saat ini serta hingga enam pesan terbaru.

Hak akses minimum

Hak administrator dibatasi untuk dua pengembang. Supabase, Google Play Console, AdMob, dan OpenAI menggunakan verifikasi dua langkah.

Dependensi dan rilis

Kami memperbarui SDK dan pustaka secara berkala serta meninjau peringatan keamanan sebelum setiap rilis. Aplikasi ditandatangani dengan Play App Signing.

Pengamanan asisten AI

  • Sebelum pertama kali digunakan, pemain diberi tahu bahwa pesan mereka dikirim ke OpenAI dan diperingatkan agar tidak membagikan informasi pribadi.
  • Pemain dapat melaporkan jawaban AI yang menyinggung atau berbahaya dari layar obrolan.
  • Percakapan tidak disimpan di basis data kami, log server kami tidak menyimpan teks pesan, dan kami tidak menggunakan percakapan untuk melatih model kami sendiri.

Pelanggaran data pribadi

Jika kami menemukan pelanggaran data pribadi, kami membatasinya, menilai risikonya dan, jika diwajibkan, memberi tahu otoritas perlindungan data dalam 72 jam. Jika risikonya bagi pemain yang terdampak tinggi, kami memberi tahu mereka tanpa penundaan yang tidak semestinya (GDPR Pasal 33–34). Kami menyimpan catatan internal atas insiden.

Melaporkan masalah keamanan

Jika Anda menemukan masalah keamanan, kirimkan rinciannya ke contact@arojentarinat.com. Mohon beri kami waktu yang wajar untuk memperbaiki masalah tersebut sebelum mempublikasikannya. Kami mengakui laporan dalam 5 hari kerja, dan kami tidak akan mengambil tindakan terhadap penelitian yang dilakukan dengan itikad baik.

Laporan keamanan: contact@arojentarinat.com. Permintaan privasi: lihat Kebijakan privasi.
