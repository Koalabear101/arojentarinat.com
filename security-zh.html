安全政策

我们尽可能少地收集数据，并保护我们持有的数据。本政策介绍我们的主要保障措施，是对隐私政策的补充。

最后更新：2026年11月1日

传输中的加密

应用与 Supabase、AI 服务器函数以及 Google 广告服务之间的通信使用 HTTPS/TLS。应用不允许未加密的 HTTP 通信。

静态数据加密

Supabase 对数据库存储进行加密。游戏存档保存在您设备上应用的私有存储中。

访问控制

我们在每一个 Supabase 数据表上都启用了行级安全（Row Level Security，RLS），因此公开密钥只能执行规则允许的操作，例如添加分析事件和读取共享内容。服务角色密钥从不随应用发布。

密钥管理

OpenAI API 密钥是 Supabase Edge Function 的服务器端机密，不会嵌入应用中。

滥用防护

AI 函数会限制每个客户端的请求数量，并且仅转发当前消息以及最近最多六条消息。

最小权限

管理员权限仅限两名开发者。Supabase、Google Play Console、AdMob 和 OpenAI 均使用两步验证。

依赖项与发布

我们定期更新 SDK 和库，并在每次发布前审查安全公告。应用使用 Play App Signing 签名。

AI 助手保障措施

  • 玩家首次使用前，会被告知其消息将发送至 OpenAI，并被提醒不要分享个人信息。
  • 玩家可以在聊天界面中举报具有攻击性或有害的 AI 回复。
  • 对话不会存储在我们的数据库中，我们的服务器日志不会保存消息文本，并且我们不会利用对话训练我们自己的模型。

个人数据泄露

如果我们发现个人数据泄露，我们会控制事态、评估风险，并在需要时于 72 小时内通知数据保护监管机构。如果对受影响玩家的风险较高，我们会在不无故拖延的情况下通知他们（GDPR 第 33–34 条）。我们保存一份内部事件记录。

报告安全问题

如果您发现安全问题，请将详细信息发送至 contact@arojentarinat.com。在公开发布之前，请给予我们合理的时间修复问题。我们会在 5 个工作日内确认收到报告，并且不会对善意开展的研究采取任何措施。

安全报告：contact@arojentarinat.com。隐私请求：请参见隐私政策。
